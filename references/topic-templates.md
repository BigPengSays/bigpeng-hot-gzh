# 8 个选题模板

语料来自 AI 工具 / Skill / 效率赛道。换赛道时复用槽位，不要硬套 Codex、WorkBuddy、Skill 这些词。

高转化选题通常同时满足三件事：

1. **具体对象**：谁的工具、哪件事
2. **可感知结果**：数字、清单、反转结论
3. **读者身份或情绪**：创作者、上班族、普通人，或慌/香/杀疯了

只有热点没有用法，或只有教程没有钩子，都偏弱。

---

## 1. 必装清单

**何时用**：用户已有一组可执行物（Skill、插件、指令、工具），或关键词是「推荐 / 必装 / 合集」。

**槽位**：身份 + 必装/推荐 + N 个 + 对象。N 必须具体。

**正例**

- 中文创作者必装的 7 个 Skill
- 上班族必装！7 个让 Claude Code 原地起飞的神级 Skill

**正文要兑现**：真有 N 条，每条能装、能用、有一句场景。

---

## 2. 亲测复盘

**何时用**：用户做过一次够夸张的实验、踩坑或批量分析，能给出反直觉结论。

**槽位**：我用 X 做了 Y（夸张量）+ 得到 Z。

**正例**

- 我让 Codex 复盘了 100 个详情页，它发现转化率最高的不是卖点，而是这 3 个位置
- 七天烧 230 亿 Token，我整理了 50 条 Codex 使用经验

**正文要兑现**：过程可复述，数字来自真实工作量，结论不是正确废话。

---

## 3. 从 0 到 1 教程

**何时用**：读者不会用、刚听说、或被功能淹没。承诺速通，常附避坑/提示词。

**槽位**：时长或字数 + 精通/速通/保姆级/手把手 + 对象。

**正例**

- 9000 字 WorkBuddy 超详细教程，手把手带你从 0 到 1，速通国内最好的 Agent
- 保姆级教程，Codex 接入 DeepSeek V4 Pro 和 Grok 4.6，6 种方法全整理

**正文要兑现**：按顺序能跟着做完；标题写了「避坑/提示词」就必须有独立段落。

---

## 4. 热点产品落地

**何时用**：新模型、新产品发布 24–72 小时内。写成普通人怎么用，不是新闻通稿。

**槽位**：产品名（尽量进前 16 字）+ 情绪或玩法数 + 附赠物。

**正例**

- 字节 Seedance 2.0 杀疯了！我总结了 7 种逆天玩法（附教程+提示词）
- DeepSeek 的顶配智能体终于上线！黑鲸鱼 Harness 开源登场

**正文要兑现**：至少一种可复现玩法。禁止只复述发布会。

---

## 5. 对比抉择

**何时用**：两个热工具同时被问「到底用哪个」，或用户有实测数据。

**槽位**：A 和 B 到底选哪个 / 实测 A 和 B + 同一任务。

**正例**

- WorkBuddy 和 Codex 到底选哪个？我帮你对比了一下
- 实测 WorkBuddy 和 Codex，同读 209 页资料：WorkBuddy 快一倍，Codex 却更靠谱吗？

**正文要兑现**：同一任务、可对比的指标、明确站队或分场景站队。

---

## 6. 开源神器安利

**何时用**：GitHub / 下载量有硬社会证明，或能替代一个读者正在用的付费工具。

**槽位**：Star/下载/热榜 + 对象 + 它解决的一件具体事。

**正例**

- 12.7K Star，这个开源项目把整本书炼成 Skill
- 杀疯了！4GB 显存跑 70B 大模型，不量化不剪枝，GitHub 狂揽 2.8 万 Star

**正文要兑现**：Star/下载数为公开可查；讲清安装与一个真实用例。禁止编造星标。

---

## 7. 身份场景化

**何时用**：工具本身不新，但接到一个具体身份或岗位就变成新选题。

**槽位**：身份 + 用 X 做 Y / 真正省事的是这一套。

**正例**

- 体制内用 WorkBuddy，真正省事的是这一套
- 电商商家使用 Codex 必装的一个作图 Skill
- 一人公司创业者必读：我用 WorkBuddy+Codex 弄懂了 Model、Tool、Skill、Harness

**正文要兑现**：场景细节必须像那个身份的人会遇到的，不是把教程换个开头。

---

## 8. 反常识 / 情绪钩

**何时用**：能挑战读者正在做的事或正在信的结论；或产品情绪已经明确（慌、拉完了、香）。

**槽位**：你以为 A，其实 B / 短口语情绪句。

**正例**

- 你觉得 Codex 不好用，可能是因为它开错了「档位」
- 等 AI 干活时刷手机，是 2026 年最贵的坏习惯

**正文要兑现**：反转要有机制解释，不能只骂一嘴。短情绪标题后面必须有干货，否则撑不住点击。

---

## 映射提示

| 用户输入像什么 | 优先模板 |
|---|---|
| 推荐、必装、合集、N 个 | 1 必装清单 |
| 我测了、踩坑、复盘、烧了多少 | 2 亲测复盘 |
| 不会用、教程、从 0 到 1、接入 | 3 从 0 到 1 教程 |
| 刚发布、杀疯了、终于来了 | 4 热点产品落地 |
| A 还是 B、对比、实测两个 | 5 对比抉择 |
| GitHub、Star、开源、替代 XX | 6 开源神器安利 |
| 电商 / 体制内 / 上班族 / 一人公司 | 7 身份场景化 |
| 吐槽、误区、反直觉、坏习惯 | 8 反常识 / 情绪钩 |
