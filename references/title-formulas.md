# 7 型标题公式

面向微信公众号信息流，不是推文 20 字标题。换赛道时复用公式，不要复用语料里的产品名。

默认每条路径 A 覆盖 **6 个不同公式**。禁止 6 条同义改写。

---

## 公式

### 1. 数字清单

结构：`身份 + 必装/推荐 + N 个 + 对象`

- 中文创作者必装的 7 个 Skill
- 上班族必装！7 个让 Claude Code 原地起飞的神级 Skill

N 必须是具体整数。禁止「多个」「一系列」「干货合集」这种空数字。

### 2. 我+代价+收获

结构：`我用 X 做了 Y（夸张量）+ 得到 Z`

- 我分析了 1000 个 skills，这是最推荐的 30 个
- 七天烧 230 亿 Token，我整理了 50 条 Codex 使用经验

代价要可感知：天数、样本数、Token、页数、时长。收获是清单或反转结论，不是「收获很大」。

### 3. 反转结论

结构：`以为是 A，其实是 B` / `不是 X，是 Y` / `从能 A 变成能 B`

- 我让 Codex 复盘了 100 个详情页，它发现转化率最高的不是卖点，而是这 3 个位置
- 你觉得 Codex 不好用，可能是因为它开错了「档位」
- 这三个 Skill，让你的大模型从「能写代码」变成「编程专家」

反转必须是正文真能证伪的常识，不能为了反转而反转。

### 4. 速成教程

结构：`时长或字数 + 精通/速通 + 对象`，或 `保姆级/手把手/你奶奶都能学会`

- 《10 分钟精通 Gemini3 和 NanoBanana2》
- 9000 字 WorkBuddy 超详细教程，手把手带你从 0 到 1
- 日行一善，你奶奶都能学会的 Hermes 教程，免费，开源
- Codex 电商实战：30 分钟做完主图、详情页和卖点文案

写了时长/字数，正文体量必须配得上。

### 5. 社会证明

结构：`Star / 下载 / 内部 / 大厂 / 热榜 + 对象 + 它干成了什么`

- 12.7K Star，这个开源项目把整本书炼成 Skill
- 我发现一个神仙 skill，20 万星，被下载近 80 万次，却只有几行字（附实测效果）
- 美团内部已经开始推广使用 Cursor

数字必须可核查。没有公开数据就不要用这条公式，改用清单或教程。

### 6. 对比站队

结构：`A 和 B 到底选哪个` / `实测 A 和 B` / `彻底抛弃了 X`

- WorkBuddy 和 Codex 到底选哪个？我帮你对比了一下
- 实测 WorkBuddy 和 Codex，同读 209 页资料
- GitHub 开源神器：这款 API 调试工具让我彻底抛弃了 Postman

对比要有同一任务。抛弃型标题必须真用过被抛弃的那个工具。

### 7. 情绪短句

结构：短、口语、带慌 / 杀疯了 / 拉完了 / 有福了 / 卷到

- Windows 这次真要慌了
- AI 剪视频，已经卷到不用你自己剪了
- 谷歌 gemini 3.5 flash 真的拉完了，全场都在叹气

默认只出 1 条情绪型。太短的标题后面必须有干货正文，否则不作为首选。

## 写法细则

- **主标题长度**：18–32 字（按可见字符计，含标点、数字、英文）。另可给 1–2 条超长信息型（带附赠括号），不作为默认首选。
- **工具名尽量出现在前 16 字**：信息流截断后仍能看懂在讲谁。
- **数字要具体**：7、10、50、100、209 页、3.5 万 Star。禁止「多个」「一系列」。
- **第一人称优先**：「我用 / 我让 / 我把 / 亲测」通常优于「如何如何」。
- **身份词是点击开关**：创作者、上班族、电商商家、普通人、体制内、一人公司。缺身份时可以补，但标「需正文按该身份写场景」。
- **口语 > 书面**：档位、杀疯了、神仙玩法、卷到、有福了。禁止空喊震惊、重磅、炸裂、必看（除非用户原稿已有且要求保留）。
- **附赠括号是履约承诺**：`（附教程+提示词）` `建议收藏` `附完整制作流程` `附开源仓库`。标题写了，正文必须有对应物。

## 缺元素时怎么补

从用户草稿里抽：对象工具、身份、数字、结果、冲突、代价、附赠物。

| 缺什么 | 可以补 | 不可以补 |
|---|---|---|
| 身份 | 按内容推断一个，并标注需兑现 | 同时堆三个身份 |
| 数字 | 用正文里真实可数的条数；没有就改用不依赖数字的公式 | 编造 Star、下载量、实验样本量 |
| 结果 | 用草稿里已有的结论收紧 | 发明没做过的「反超 8.7 分」 |
| 附赠 | 仅当用户确实会提供教程/提示词/仓库 | 空挂「附完整教程」 |

## 禁用与弱标题

- 通稿体：`XX 发布了` `盘点 XX` `关于 XX 的思考`
- 正确废话：`AI 正在改变我们的工作方式`
- 同义改写：6 条标题公式重复或只改两个字
- 把语料产品名硬套进无关选题
