# 示例 Prompt

三类调用：已有选题起标题、只有关键词出方向、空输入套热点。Agent 应走对应路径，不要两边都做。

---

## 1. 已有选题 → 候选标题（路径 A）

```text
用 bigpeng-hot-gzh 帮我起几个爆款公众号标题。

草稿：我把最近两个月用 AI 做小红书封面的流程收成了 8 个 Skill，从选题、文案、出图到封面文字都覆盖。目标读者是自己做号的中文创作者。正文里会写每个 Skill 装法和一个真实用例。
```

预期：走路径 A，6 条不同公式；工具/Skill 名尽量靠前；数字用 8，不要编造 Star。

示意输出（节选，不是唯一答案）：

```markdown
## 选题理解
给自己做小红书的中文创作者，把封面生产收成 8 个可安装 Skill。

## 候选标题

1. **中文创作者必装的 8 个小红书封面 Skill**
   - 公式：数字清单
   - 字数：22
   - 为何可能点：身份 + 具体数字 + 场景
   - 兑现：正文必须真有 8 个，每个有装法和用例

2. **我把小红书封面流程收成 8 个 Skill，从选题到出图不用再临时想**
   - 公式：我+代价+收获
   ...

## 首选
**中文创作者必装的 8 个小红书封面 Skill**
截断后仍能看懂给谁、几条、干什么；数字来自草稿，能兑现。
```

---

## 2. 只有关键词 → 方向 + 标题（路径 B）

```text
用 bigpeng-hot-gzh 给几个公众号选题。
关键词：WorkBuddy，体制内办公
```

预期：走路径 B，约 4 个方向，模板不重复（例如身份场景化、必装清单、对比抉择、从 0 到 1 教程）；不要写成发布会通稿。

示意输出（节选）：

```markdown
## 输入理解
关键词：WorkBuddy × 体制内办公

## 方向 1：体制内把周报、会议纪要、请示从聊天里搬进可复用流程
- 模板：身份场景化
- 为什么现在能写：工具热，但缺「像体制内的人会遇到的事」
- 建议证据：一份真实周报前后对比，或一套请示模板

1. **体制内用 WorkBuddy，真正省事的是这一套**（情绪短句变体 / 兑现：必须是那一套具体流程）
2. **我用 WorkBuddy 把周报从 2 小时压到 20 分钟，体制内同事开始来问**（我+代价+收获）
3. **体制内必装的 6 个 WorkBuddy 办公 Skill**（数字清单）

## 最值得先写
方向 1 + 体制内用 WorkBuddy，真正省事的是这一套
身份明确、可执行、不依赖刚发布的新品。
```

## 3. 空输入 → 套当前热点（路径 B）

```text
用 bigpeng-hot-gzh，最近公众号写点什么？
```

预期：空输入走路径 B；先 WebSearch 当前可写热点，再套模板。禁止只从语料里抄 Seedance / HyperFrames 等过时例子当「本周选题」，除非搜索证明它仍在热。

示意输出结构：

```markdown
## 输入理解
空输入。当前热点用了：……（产品/事件 + 为何 24–72 小时内可写）

## 方向 1：……（热点产品落地）
...

## 最值得先写
……
```

---

## 反例（不要这样做）

```text
帮我起标题：Claude 新模型发布了
```

弱：通稿体、没有用法和身份。应改成热点产品落地（普通人怎么用）或对比抉择，并补兑现点。
